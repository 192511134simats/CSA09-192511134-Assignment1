The Campus Smart Parking System is an object-oriented Java application designed to manage parking facilities within a university campus.

The system supports different vehicle categories, parking slot allocation, vehicle entry and exit, parking fee calculation and electric vehicle charging fees.

How to Compile and Run

Using an Online Java Compiler

1. Open https://www.programiz.com/java-programming/online-compiler/
2. Copy the required Java program.
3. Paste the code into the editor.
4. Click the Run button.
5. Compare the actual output with the expected output.
6. Save the output screenshot in the corresponding task folder.

Using Command Prompt

1. Install the Java Development Kit (JDK).
2. Open Command Prompt in the folder containing the Java file.
3. Compile the program:

javac FileName.java

4. Run the program:

java ClassName

Replace "FileName" and "ClassName" with the actual names used in each program.
